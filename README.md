# Entrepreneur Koshien 2022

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository archives the business plans from the Entrepreneur Koshien 2022 competition in Japan, enriched with AI-generated feedback. It includes the open data, scripts for processing, and a static website to showcase the results.

## Live Demo

View the project showcase with AI-generated advice on GitHub Pages:

**➡️ [https://code4fukui.github.io/kigyoka-koshien-2022/](https://code4fukui.github.io/kigyoka-koshien-2022/)**

The site presents each team's business plan, including their abstract and development suggestions provided by an AI.

## Automation Scripts

This project uses several Deno scripts to process data and build the static site:

-   `cnv.js`: Converts raw text data into the base `kigyoka-koshien-2022.json` file.
-   `make-comment.js`: Sends each business plan abstract to a chat AI to generate development advice and saves the results.
-   `afterprocess.js`: Cleans the AI-generated comments and adds absolute image paths.
-   `makehtml.js`: Generates the static HTML pages for the demo site in the `docs/` directory from the final processed data.

## Usage

The data files can be used directly. For example, to extract the title of the first entry using `jq`:

```bash
cat kigyoka-koshien-2022.json | jq '.[0].title'
```
